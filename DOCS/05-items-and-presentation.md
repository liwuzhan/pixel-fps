# 物资、背包与示意表现

本轮接通“看见物资—认出类别—拾取—选择使用—看到结果—丢回场地”。它服务于玩法验证：图标和粗模能够区分手枪、步枪、小刀、火箭筒、弹药、蓝瓶与技能，动效能够表达攻击已经发生。当前不追求写实。

## 系统边界

| 系统 | 负责什么 | 修改状态的边界 |
| --- | --- | --- |
| 内容定义 `content.js` | 武器与资源的名称、说明、伤害、射速、消耗量等参数 | 不读键盘、不建 DOM、不生成模型；技能参数仍在各自技能定义中 |
| 背包 `inventory.js` | 武器实例、资源数量、各级技能份数；增减、选择、三合一 | 不决定地面位置、拾取距离、伤害、冷却或动画 |
| 世界 `world.js` | 地面物资、拾取与丢弃条件、转移、武器开火、碰撞、爆炸、伤害 | 先检查世界条件，再通过背包增减物资；产生可观察的结果和事件 |
| 技能运行入口 `skill-runtime.js` | 持有检查、耗蓝、冷却、发动与持续实例生命周期 | 调用具体技能脚本；丢弃材料不修改正在运行的实例与冷却 |
| 玩家操作 `player-actions.js` | 把按键或结构化请求映射为切换、使用、丢弃、合成 | 不依赖 DOM；把业务处理交给世界、背包或技能运行入口 |
| 背包面板 `inventory-panel.js` | 图标、数量输入、等级、冷却、合成与快捷键选择 | 通过玩家操作入口提交请求，不直接扣库存或制造命中 |
| 示意资源 `item-visuals.js` | 编号对应的 SVG 图标和方块粗模 | 只描述外观，不定义射程、碰撞盒与伤害 |
| 绘制 `renderer.js` | 地面粗模、手持武器、投射物、后坐与爆炸等效果 | 读取世界状态和游戏时间；不修改世界或推进结算 |
| 页面 `app.js` | 浏览器输入、暂停窗口、HUD、存储与固定步长更新 | 连接各系统；实验接口与正常操作使用相同结算入口 |

例如，玩家按 B 后，操作入口找到当前武器实例并请求世界丢弃。世界找到可用位置，背包转出该实例，世界创建地面物资并记下事件。图标和模型读取结果显示；它们不会另建一把可造成伤害的武器。

以后更换渲染方式或进入专用引擎，可以替换图标、模型、动画和页面接入。碰撞与运动如何接入新引擎仍需适配；这里的边界保证显示代码不会同时藏着另一套库存或伤害规则。

## 物资怎样流转

| 类别 | 持有方式 | 丢弃与再拾取 |
| --- | --- | --- |
| 武器 | 每把都是 `{ id, type }` 实例，同类武器可以同时持有多把 | 按实例丢弃，重新拾取保留原编号；切换、丢弃其他武器不应意外换掉当前手持武器 |
| 通用弹药 | 一个共享数量 | 按指定正整数拆出一组，拾取后加回储备；武器按自己的消耗量扣除 |
| 蓝瓶 | 一个数量 | 按指定数量拆出一组；使用一瓶恢复当前蓝量，不能超过体型决定的容量 |
| 技能材料 | 每个技能分别记录各等级份数 | 指定等级与数量丢弃；拾取保留等级，普通技能仍可同名同级三合一 |

拾取使用玩家脚边位置检查可达性，避免高个角色因为视点太高捡不到地上物品。它同时检查距离、垂直距离和墙体遮挡。丢弃先寻找脚边可用位置；数量、等级或放置条件不满足时返回原因，不扣物品。

当前地面物资没有重力模拟，放好后位置固定。角色在空中丢弃物资时，物资会停在相应高度；地面模型的小幅浮动只是显示效果。物资不会自动刷新，也没有背包负重、格子容量、死亡掉落或穿戴规则。这些规则仍待玩法需要明确后再加入。

技能持有量与施法状态分开。丢掉技能再捡回来不清除冷却；丢掉最后一份普通技能后无法再次发动，已经产生的投射物或持续效果仍按各自生命周期运行。消耗型终极发动扣除材料，已启动的效果不会因为背包份数归零消失。

## 背包与快捷使用

正常训练中按 Tab 打开背包并暂停。窗口内 Tab 用于焦点导航，Esc 关闭。资源行可输入丢弃数量；武器行可选择手持或丢弃；技能行显示说明、等级分布、冷却、使用与三合一按钮，并可分配快捷键。

| 操作 | 入口 |
| --- | --- |
| 拾取附近可达物资 | E |
| 丢弃当前武器 | B |
| 切换武器 | 滚轮循环，数字 1–9 选择前九把；背包可选择全部武器 |
| 使用蓝瓶 | V，或背包“使用一瓶” |
| 发动技能 | 已绑定按键，或背包“使用” |
| 设置技能键位 | 背包内选择 Q、F、G、R、C、X、Z、T，也可取消绑定或恢复默认 |

默认 Q 为弹射背包、F 为自瞄、G 为虚弱榴弹。一个按键绑定一个技能，一个技能至多绑定一个按键；重新分配会移除其旧绑定。快捷键数量只决定同时显示的操作入口，不限制背包持有的技能种类或持续技能实例数量。

键位存入浏览器 `localStorage` 的 `fps.controls.v1`，与角色存档及实验场景分开。加载实验或重新训练不应覆盖玩家绑定；浏览器禁止存储时仍可在本次页面中使用。

自动化可以调用相同入口：

```js
const actions = PixelFPSApp.actions;
actions.selectWeapon(0);
actions.drop({ kind: "ammo", amount: 12 });
actions.drop({ kind: "skill", skillId: "weaken", level: 1, amount: 3 });
actions.bindSkill("KeyR", "weaken");
actions.useSkill("weaken");
```

操作返回 `{ ok, message }`，转移结果还可带物资对象。`bindSkill` 只修改内存映射，页面负责持久保存；底层操作不会自行访问浏览器存储。

## 火箭筒验证了什么

火箭筒用来验证同一件武器的地面显示、背包图标、手持粗模、共享弹药、真实飞行、爆炸和再次丢弃。

| 当前参数 | 验证值 |
| --- | --- |
| 编号 | `rocket` |
| 每次共享弹药消耗 | 6 |
| 两次开火间隔 | 0.9 秒 |
| 弹速 | 22 米/秒 |
| 投射物判定半径 | 0.12 米 |
| 爆炸范围 | 3.5 米 |
| 原始伤害 | 80 |

火箭碰到障碍或敌人后爆炸。爆炸按六个真实部件检查范围与遮挡，每个敌人最多结算一次；直接命中的对象不会再额外叠加一份接触伤害。当前范围内不按距离衰减，也不伤害发射者或同队角色。伤害仍通过共同入口，所以虚弱、无敌、木桩自动恢复和战斗日志继续生效。这些数值和敌我规则都是当前原型的可观察行为，后续可调整。

实验台加载 `rocket`，或控制台输入 `scenario load rocket`，会给玩家火箭筒与 100 份弹药，放置三个相邻木桩。可以用慢放和逐帧观察飞行、碰撞、范围效果，再检查伤害与爆炸日志。

## 显示怎样跟随结果

物资用轮廓与颜色共同区分：手枪短、小刀细长、步枪长身、火箭筒管状；技能与资源使用各自符号。背包、HUD、拾取提示和场地模型按相同编号查找显示资源。新内容没有专用外观时使用通用示意。

开火结算产生效果，绘制读取这些效果表现枪口闪光、后坐或刀挥；火箭显示尾迹，爆炸显示扩散圈。效果使用 `world.time`，实验暂停时不会自行播放完。爆炸圈提示此次范围，但判定依然读取世界中的半径、部件几何和墙体，不读取模型或像素。

本轮没有声音系统、复杂动画混合、骨骼与写实材质。若继续添加反馈，先由结算产出清晰的事件，再由表现部分消费，避免在动画回调里扣弹、扣血或改变库存。

## 增加下一件内容

- **只改变参数的武器**：在 `content.js` 添加定义，复用现有攻击行为；按需补图标和粗模。物资布置仍需明确安排。
- **新的攻击行为**：先补世界或相应战斗模块的能力，再由定义选择行为；不在渲染器中实现命中。
- **新技能**：在 `src/skills/` 添加独立注册脚本，构建会自动包含；背包、实验台与绑定界面动态读取定义。需要正常拾取时另行布置掉落，专用图标与模型可后补。
- **新的实验**：使用实验台发放物资、配置木桩并保存场景。版本 2 精确保存地面物资和武器身份，方便重复验证转移与攻击。

新增内容仍应验证实际效果、资源消耗与结束清理。框架已支持的东西主要填写定义；全新行为需要扩展对应能力，不必预先为所有候选点子搭建通用编辑器。
