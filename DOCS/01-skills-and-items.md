更新日期：2026-09-24

阶段：玩法清单持续讨论；首轮单机战斗 demo 已实现，具体范围见下表。清单中保留的点子不等于已经做进游戏。

这份文档记录当前讨论结果。A 组是已经提出并保留的方向；B 组是新补充的候选；C 组是尚未展开或暂存的想法。保留一个方向，不代表所有细节已经确定。

## 当前可以试玩的内容

主入口为 `index.html`，可离线打开。它包含第一人称训练场和嵌入的捏人、画脸编辑器；`block-character.html` 保留为独立编辑器。项目仓库：[liwuzhan/pixel-fps](https://github.com/liwuzhan/pixel-fps)。

| 内容 | 本轮实现 |
| --- | --- |
| 身体与战斗 | 六方块体型接入血蓝容量、移动速度、小刀范围、移动碰撞和受击判定；可绘制头部正面贴图 |
| 武器与补给 | 地面拾取手枪、步枪、小刀、通用弹药、蓝瓶；切枪；枪弹实际飞行并与场景和身体部件碰撞 |
| 弹射背包 | 普通技能；向上弹射并获得少量水平推力，使用消耗蓝量并进入冷却 |
| A02 自瞄 | 消耗型终极；锁定准心周围、没有遮挡的敌人，修改实际瞄准方向，仍由玩家开火 |
| 虚弱榴弹 | 普通技能；实体榴弹撞击后给直接命中或范围内无遮挡的敌人施加降低伤害输出的状态 |
| 背包与合成 | 显示物资、各等级技能份数与冷却；普通技能手动三合一，可继续合成高一级；自瞄按份消耗，允许多个发动实例同时持续 |
| 训练条件 | 三个不同体型的靶子；可开关移动与还击、复位靶子或重新开始 |

这是单机验证场，尚无联机、胜负或死亡掉落规则。负重、特殊装备、虚影以及清单里的其余能力仍待实现。当前枪械直接消耗通用弹药，没有弹匣和换弹；角色以满血满蓝进入训练场，无自然回蓝。以上操作和所有伤害、耗蓝、冷却、升级效果数值均为验证实现，不作为后续平衡定案。

## 共同规则

- 当前网页 3D 项目是玩法验证 demo，优先验证规则与组合，视觉表现只需清楚可辨。
- 每个技能对应自己的脚本，通过共用的角色、移动、瞄准、投射物和状态等接口作用于目标。具体组织见 [技能脚本与玩法验证 demo](03-skill-scripts-and-demo.md)。
- 武器、技能、终极技能、装备、弹药和恢复用品等物资均通过拾取获得。
- 普通技能获得后可以重复使用，受冷却以及技能自身的资源条件影响。
- 技能支持三合一升级，升级后还可以继续三合一。当前按“同名、同等级的三份合成一份高一级技能”理解；升级提升什么效果、最高等级及具体合成操作待定。普通技能重复拾取可用于升级；终极消耗品是否也参与合成另定。
- 终极技能按消耗品处理，使用消耗一份。与普通技能的区别首先是消耗方式，不按效果强弱划分。
- 能拥有和同时使用多少个终极技能，取决于拾取情况与蓝量；不额外规定终极技能槽位上限。
- 普通枪弹采用实际飞行的投射物，在飞行中参与碰撞，命中后结算效果。速度、外观及是否下坠按武器另定。
- 枪械使用同一种通用弹药资源，避免为不同枪种增加不同弹药掉落物。全部采用能量枪、拾取电池是可选表现方案，尚未确定美术设定。弹匣、换弹和各武器每次消耗量另定。
- 头部大小决定蓝量容量，蓝瓶补充当前蓝量。当前蓝量、初始蓝量与自然回蓝不是同一个问题，后两项尚未定案。
- 当前先整理玩法及其逻辑，不确定伤害、冷却、耗蓝等平衡数值。下文的 5 倍与 5 秒来自讨论示例或暂定值。
- 游戏模式、胜负方式、撤离、死亡后物品处理、野怪与角色成长等级尚未确定。

## 基础武器与补给

基础战斗先考虑手枪、小刀。枪械统一使用通用弹药；不同枪仍可以拥有不同的射速、单次消耗、投射物表现和攻击效果。弹药可表现为子弹补给，也可表现为能量电池，具体外观以后决定。

其他枪械、通用弹药、血瓶、蓝瓶另列详细表。血瓶与蓝瓶恢复当前资源，体型决定的容量另外计算。蓝量与枪械弹药分别记录。

## 技能合成的当前理解

三合一升级方向已确认，以下按同名、同级合成展开。当前 demo 在背包中手动触发普通技能合成：每次选择一个材料足够的最低等级，消耗三份，生成高一级的一份。

| 合成材料 | 合成结果 | 折合一级技能数量 |
| --- | --- | --- |
| 3 份一级同名技能 | 1 份二级技能 | 3 份 |
| 3 份二级同名技能 | 1 份三级技能 | 9 份 |
| 3 份三级同名技能 | 1 份四级技能 | 27 份 |

升级不改变普通技能可复用、终极技能消耗使用的区别。当前 demo 使用持有的最高等级发动，同名普通技能共用冷却，合成不刷新冷却；剩余低级份数继续留作材料。自动还是手动合成的最终操作、同名技能的使用关系、是否适用于终极消耗品，以及各等级的具体效果，继续保留为待定内容。

## 体型规则背景

角色由六个长方体组成：头、躯干、两臂、两腿。捏人参数为头部大小、躯干大小、双臂共同长度、双腿共同长度。头部和躯干按比例缩放，四肢只改长度；身高由尺寸自然得出。面部只在头部正面绘制贴图。

| 身体条件 | 已讨论的关联方向 |
| --- | --- |
| 头部体积 | 蓝量容量 |
| 躯干体积 | 血量容量、携带能力 |
| 腿长 | 基础移动速度 |
| 臂长 | 近战攻击范围 |
| 实际身体形状与尺寸 | 受击范围、遮挡、隐藏与通行能力 |

关系方向已经讨论。demo 暂用头部体积比例换算蓝量容量、躯干体积比例换算血量容量、腿长比例换算移动速度，以臂长计算小刀触及距离；这些公式用于验证关联，尚未定案。躯干与负重的关系尚未实现。初始捏人的参数范围与战斗中的临时整体缩放是两个不同层面的规则，整体巨大化仍在清单中。
