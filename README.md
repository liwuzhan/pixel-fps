# Pixel FPS · 玩法验证 demo

一个可以捏体型、画脸、收集武器与技能的网页 FPS 原型。当前版本是带背包、可配置快捷键、实验木桩和作弊控制台的单机训练场。图标、方块粗模与简单动效用于辨认物资和观察结果；数值只是让规则可观察的测试值。

仓库：<https://github.com/liwuzhan/pixel-fps>

## 开始试玩

下载仓库后，用桌面浏览器打开根目录的 **`index.html`**。不需要安装依赖或联网，浏览器需要支持 WebGL。`block-character.html` 是可单独打开的捏人与画脸模块。

1. 点击“进入训练场”，在出生点附近按 **E** 拾取手枪和通用弹药。
2. 向前走可捡到三种技能；左右还有小刀、步枪、火箭筒、额外弹药和蓝瓶。
3. 向前方训练靶射击；按 **Tab** 查看图标背包，切换武器、按数量丢弃物资、合成技能或重新分配技能快捷键。窗口内 Tab 用于焦点导航，Esc 关闭窗口。
4. 按 **Esc** 暂停，可修改体型、画脸，或在训练设置里开启靶机回击。
5. 在角色编辑器点击“应用角色并重新训练”，新体型会进入训练场，同时重置本轮物资与状态。

| 操作 | 按键 |
| --- | --- |
| 移动 / 冲刺 / 跳跃 | WASD / Shift / 空格 |
| 瞄准 / 攻击 | 鼠标 / 左键 |
| 拾取 / 丢弃当前武器 | E / B |
| 切换武器 | 滚轮；数字 1–9 对应背包前九把武器 |
| 弹射背包 / 自瞄 / 虚弱榴弹 | 默认 Q / F / G，可在背包重绑 |
| 可分配的技能快捷键 | Q、F、G、R、C、X、Z、T |
| 使用蓝瓶 / 背包 | V / Tab |
| 暂停并释放鼠标 | Esc |
| 打开 / 关闭实验台 | F2 / 反引号（`） |

当前按桌面键鼠操作验证；没有移动端触屏战斗控制。角色参数、画脸和技能键位会在浏览器允许时自动保存，角色也可以导出、导入 JSON。快捷键只是使用入口，不限制技能持有种类；没有绑定的技能仍可从背包使用。战斗进度暂不保存；实验台可以保存用于重新布置场地的配置。

## 最快开始实验

1. 在开始页点“实验台”，或进入训练后按 **F2 / 反引号**；暂停菜单也有入口。
2. 选择“基础射击”“连续三合一”“虚弱与还击”或“火箭筒与范围爆炸”，加载后点“继续训练”。物资与木桩已经布置好。
3. 再打开实验台，修改选中木桩的体型、坐标、移动、还击、非致命受伤后补满生命和死亡后自动复活。
4. 控制台输入 `help` 查看指令；例如 `give skill weaken 9 1` 发放九份一级虚弱榴弹，`give ammo 999` 补充共享弹药。
5. 在战斗记录里查看命中部位、原始伤害、状态倍率和实际扣血；可筛选或导出 JSON。

实验台打开时训练自动冻结。逐步观察时点“前进 1 帧”或“前进 1 秒”；每帧是 1/120 游戏秒。点“继续训练”恢复运行；慢放同时影响弹丸、移动、状态、技能冷却与复活计时。无限蓝量、无限弹药、无技能冷却都作用于实际结算，消耗型终极仍然需要并消耗技能份数。

自存实验可在当前浏览器保存，也可以导出、导入 JSON。版本 2 逐件保存地面物资，并保留背包和地面武器的实例编号、各级技能份数、体型、位置、木桩行为与实验开关；兼容旧版实验配置。加载时重新开始结算，不恢复已飞出的子弹或未结束的技能。完整指令和自动化接口见 [实验木桩与控制台](DOCS/04-laboratory.md)。

## 已经接通的玩法

- **六方块角色**：头部、躯干、两臂、两腿。头和躯干分别等比例缩放；手臂共用长度，腿共用长度；身高由几何自然得出。保留 0.50 m、1.80 m、5.00 m 预设及更宽的调整范围。
- **身体参与战斗**：头部体积决定蓝量容量，躯干体积决定生命容量，腿长决定移动速度，臂长决定小刀距离。玩家视点、移动碰撞和受击盒使用实际体型。躯干与负重的关系尚未实现。
- **基础攻击**：手枪、步枪的子弹与火箭实际飞行，小刀近战；统一通用弹药。高速弹丸扫过路径判断墙和六个部件，腿间等空隙可以穿过。火箭每次消耗六份弹药，碰撞后对范围内无遮挡敌人造成伤害。本轮各部位伤害相同。
- **拾取与背包**：出生时空背包；枪、弹药、蓝瓶、技能都从地面拾取，可再丢回场地。弹药与蓝瓶按数量丢弃，技能按等级与数量丢弃，武器拾取和丢弃保留同一个实例。墙体阻挡拾取，放置位置不可用时不扣物品。
- **识别与操作**：背包、HUD 与拾取提示使用统一图标；地面及手持武器使用可区分的粗模。技能可重绑快捷键，也可在背包直接使用；持有数量不受快捷键数量限制。
- **示意动效**：枪口闪光、武器后坐、小刀挥动、火箭尾迹与爆炸圈反映已有结算；动效跟随游戏时间，暂停时冻结，不参与命中与伤害计算。
- **普通技能**：弹射背包改变自身速度；虚弱榴弹飞行、碰撞爆开，给范围内无遮挡敌人施加限时减伤输出状态。使用耗蓝并进入冷却，不消耗技能份数。
- **消耗型终极**：自瞄消耗一份，持续修改真实瞄准方向，枪仍需手动开火，子弹仍需实际命中。可重复发动，各次持续效果分别记录；不设终极槽位限制。
- **三合一**：背包内手动合成普通技能，同名同级三份换高一级一份，能够继续向上合成。低级剩余份数保留，施放使用当前最高等级，合成不会清除已有冷却。
- **训练反馈**：移动靶、靶机回击开关、血蓝、弹药、技能冷却和虚弱提示，可恢复训练靶或重新开始。
- **实验环境**：每个木桩独立配置，控制台与可调用接口共用操作；可发放物资、施加状态、调整时间、逐帧推进并记录伤害来源及拾取、丢弃。内建四组实验，自定义场景可以保存和导出。

每个技能对应自己的脚本，调用共同的运动、瞄准、投射物、状态与资源能力。当前用三个技能验证这种组织方式。

## 本轮边界

当前已实现基础战斗链路及用于重复验证的实验环境。创意清单中的武器库展开、无敌虚影及本体连线、巨大化、反重力、定向反射、运动封存、假人透视等仍待实现。

当前没有联机、正式游戏模式、胜负循环、负重规则、穿戴装备、弹匣与换弹、爆头倍率、跌落伤害或地图编辑器。枪械直接消耗共享弹药；角色初始满血满蓝，无自然回蓝。普通技能使用手动合成，终极合成暂未开放。这些都是当前验证范围，不代表后续规则已经定案。

为简化碰撞，身体方块当前保持世界轴对齐，视角可以自由转动；尚未实现随朝向旋转的身体和旋转碰撞。第一人称绘制手持武器粗模，不绘制自己的身体，画脸可在编辑器中检查。丢弃物保存在放置位置，不模拟落体；空中丢弃的物资会悬停。火箭当前不伤害自己或队友，爆炸范围内无距离衰减；这些是可观察的原型规则。

## 画脸

1. 调整体型后，点“下一步：画脸”或“02 画脸”。
2. 在右侧正方形画板上按住鼠标或手指绘制。左侧放大预览头部，可以旋转查看。
3. 选颜色、改笔宽；选“橡皮”擦除。空白和擦除区域保留头部底色。
4. “撤销”“重做”按完整一笔操作，最多保留 30 次。画板获得焦点时也支持 Ctrl/Command+Z、Ctrl/Command+Shift+Z，或 Ctrl/Command+Y。
5. 点“导出角色”，得到包含体型和面部图片的一个 JSON 文件。

画板为 128×128 像素，笔迹是硬边像素画。图片始终覆盖头部正面，按头部尺寸等比例显示；擦除使用透明度，不会画出底色补丁。新角色的画板为空，没有自动添加五官。

## 调整规则

| 部件 | 默认尺寸：宽 × 高 × 深 | 调整范围 |
| --- | --- | --- |
| 头部 | 0.40 × 0.40 × 0.40 m | 等比例大小 0.15–5 倍 |
| 躯干 | 0.48 × 0.60 × 0.28 m | 等比例大小 0.15–5 倍 |
| 每条手臂 | 0.16 × 0.65 × 0.22 m | 长度 0.04–4 m |
| 每条腿 | 0.20 × 0.80 × 0.24 m | 长度 0.04–4 m |

大小倍数作用于边长；体积随该倍数的三次方变化。四肢的宽、深不随躯干变化。

头部底面连接躯干顶面，手臂从躯干顶部向下延伸，两腿从同一个髋部高度向下延伸。角色坐标中 +X 为角色左侧，+Y 为上，+Z 为正面。

两腿始终等长。手臂长过腿、低于脚底时，预览以整个模型的最低点落地，并分别显示自然身高和模型总高。允许夸张比例，不强行限制为人体比例；极端组合可能造成部件相交。

## 源码与构建

| 文件 | 作用 |
| --- | --- |
| `index.html` | 单文件离线训练场，内嵌角色编辑器 |
| `block-character.html` | 单文件离线角色编辑器 |
| `src/character.js` | 纯几何、参数校验与角色数据格式 |
| `src/viewport.js`、`src/face-painter.js`、`src/app.js` | 角色预览、画板、编辑与保存 |
| `src/game/content.js` | 武器与资源定义，不含 UI 和具体显示几何 |
| `src/game/inventory.js` | 背包份数、技能等级、武器实例与转入转出，不处理世界位置和技能计时 |
| `src/game/world.js` | 身体属性、移动碰撞、地面转移、武器、投射物、爆炸和状态结算 |
| `src/game/player-actions.js` | 不依赖 DOM 的玩家操作入口与技能键位映射 |
| `src/game/inventory-panel.js` | 图标背包、数量输入、合成与绑定界面，修改通过操作入口提交 |
| `src/game/item-visuals.js` | SVG 图标与方块粗模定义，不包含伤害规则 |
| `src/game/skill-runtime.js` | 持有/耗蓝/冷却检查、实验开关与各次技能执行记录 |
| `src/game/lab.js` | 实验接口、控制台指令、时间控制、场景配置与校验 |
| `src/game/lab-panel.js` | 实验台界面、木桩表单、指令历史、战斗日志及 JSON 导入导出 |
| `src/skills/*.js` | 弹射背包、自瞄、虚弱榴弹的独立脚本 |
| `src/game/renderer.js` | 读取世界状态与效果，绘制场景、手持粗模和动效 |
| `src/game/app.js`、`shell.html`、`style.css` | 浏览器输入、HUD、窗口、设置保存、暂停与编辑器接入 |
| `build.py` | 将源码打包成两个离线 HTML；自动包含 `src/skills/*.js`，无第三方构建依赖 |
| `tests/*.test.mjs` | 几何、战斗、技能、木桩与实验接口的自动测试 |

修改 `src` 后，在仓库根目录运行：

```sh
python3 build.py
node --test tests/*.test.mjs
```

需要 Python 3 和 Node.js（支持内置 `node:test`）。运行生成后的页面不需要它们。提交源码时也更新两个生成后的 HTML，以便直接下载试玩。

角色使用版本 3 JSON：四项参数与内嵌的 128×128 面部 PNG。`BlockCharacter.createCharacter(parameters)` 返回六个部件的尺寸与中心位置；`exportData(parameters, face)` 导出；`parseProject(json)` 校验并导入。旧版本左右长度不同时，每对取平均值成为共用长度，面部图片按旧版兼容规则保留。

自动测试覆盖体型边界、旧版迁移、面部数据校验、共享弹药、弹丸扫掠与墙体遮挡、六部件空隙、移动与场地边界、三合一数量守恒、技能消耗/冷却/并发、虚弱状态及爆炸遮挡。浏览器验证覆盖离线启动、键鼠移动和射击、拾取、背包合成、技能发动及角色编辑接入。

本轮通过 94 项逻辑测试和 9 组浏览器集成验证。物资链路覆盖数量与等级守恒、武器实例转移、失败操作不扣库存、拾取遮挡、火箭共享弹药与爆炸遮挡、快捷绑定和场景版本迁移。浏览器检查包含 1280 像素桌面与 390 像素窄屏布局，未发现 JavaScript 或 WebGL 错误；窄屏布局可查看界面，不表示已支持触屏战斗。
